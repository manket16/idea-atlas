# The Idea Atlas

An immersive collection of 50 essays, lectures, and ideas across 10 disciplines.

Each entry follows: topic → large original illustration / source link → summary. Includes search, subject filters, a complete index, and browser-local bookmarks.

A curated editorial selection, not an objective ranking. Summaries and illustrations are original; linked works belong to their respective authors.

## Website

Published with GitHub Pages. The site runs directly from these static files without a build step.

## Editing

- `ideas.js`: titles, summaries, subjects, and source links.
- `style.css`: layout, typography, and colors.
- `app.js`: search, filtering, index, and bookmarks.
- `art/`: original SVG illustrations.

For a local preview, serve this folder using any static web server.
